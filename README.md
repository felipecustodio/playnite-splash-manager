# Playnite Splash Manager

A web application to discover and manage splash screen packages for Playnite - your game library manager.

## Features

- 🎬 **Video Splashes** - Beautiful video splash screens to enhance your Playnite experience
- 🖼️ **Image Collections** - Curated collections of splash screen images for every mood and theme  
- 📦 **Package Manager** - Organize and manage your splash packages with an intuitive interface

## Getting Started

Simply open `index.html` in your web browser to start exploring splash packages for Playnite.

## About

This application follows the same styling and organization pattern as the [Playnite Sounds Manager](https://github.com/felipecustodio/playnite-sounds-manager), featuring:

- Modern glassmorphism design with Tailwind CSS
- Animated backgrounds and smooth transitions
- Playnite branding and color scheme
- Interactive elements and responsive layout

## Technology Stack

- Pure HTML, CSS, and JavaScript
- Tailwind CSS for styling
- Inter font for typography
- Glassmorphism design patterns
